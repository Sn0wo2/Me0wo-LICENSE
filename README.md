### Axis 2 — Strong copyleft vs Relaxed

* **Strong copyleft editions** (`LICENSE`, `LICENSE-NC`) require **source disclosure**:

### Choosing an edition

* Want maximum openness and a strong copyleft guarantee that derivatives stay open? Use `LICENSE`.
* Building a commercial product and don't want to disclose source or force same-license on derivatives? Use `LICENSE-RELAXED`.
* Want to reserve commercial rights for yourself while keeping non-commercial use open, with strong copyleft? Use `LICENSE-NC`.
* Want to reserve commercial rights but allow non-commercial use without source disclosure? Use `LICENSE-NC-RELAXED`.
